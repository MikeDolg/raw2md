# Font assets

`HansHand-cyr.ttf` is a free Cyrillic handwriting font used to synthesise
handwritten test pages in the round-trip harness (see
`tests/synthesis/gen_pdf.py`). It is committed so the handwriting branch runs on
a fresh checkout instead of being skipped.

Origin: free handwritten Cyrillic font collections (localfonts.eu, rufonts.ru,
fontesk.com and similar). Redistributed here for test fixtures only.
