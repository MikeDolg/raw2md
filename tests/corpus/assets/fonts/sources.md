# Font assets

`Caveat-Regular.ttf` is a handwriting font with Cyrillic glyphs. The round-trip
harness uses it to render handwritten test pages (see
`tests/synthesis/gen_pdf.py`). It is committed so that the handwriting branch
runs on a fresh checkout and is not skipped.
