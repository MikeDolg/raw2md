# Обработка сканированных документов

## Введение

Сканированные документы остаются основным источником данных там, где бумажный
архив переводится в электронный вид. В отличие от файлов с текстовым слоем, скан —
это изображение страницы, и извлечь из него текст можно только распознаванием.
Качество результата зависит от исходного материала, выбранного движка и
последующей вычитки.

Ниже разобраны основные стадии обработки, типичные дефекты и приёмы оценки
качества.

## Стадии обработки

Обработка одного документа проходит несколько шагов:

1. Определение типа файла и подходящего движка.
2. Конвертация или распознавание с выносом изображений в отдельную папку.
3. Очистка разметки: исправление однозначных дефектов.
4. Оценка качества по набору проверок.
5. Сохранение результата со служебным заголовком.

Шаги выполняются строго по порядку: следующий документ берётся в работу только
после полного завершения предыдущего.

### Выбор движка

Движок выбирается по типу файла:

| Тип | Движок | Особенность |
|---|---|---|
| PDF | распознавание | работает и со сканами |
| DOCX | прямая конвертация | сохраняет структуру |
| DjVu | через изображение | требует промежуточного шага |

### Очистка разметки

Очистка делит дефекты на два класса. Однозначные исправляются сразу: лишние
пустые строки, висячие пробелы, отсутствие пробела после знака заголовка.
Неоднозначные размечаются и оставляются для последующей доработки.

> Очистка не меняет содержание текста. Её задача — убрать механические дефекты
> разметки, не затрагивая слова.

## Оценка качества

Качество результата оценивается по нескольким независимым признакам. Ни один из
них по отдельности не является приговором, но их сочетание позволяет отделить
удачный результат от провального.

Ключевые показатели:

- **Плотность текста** — число символов на страницу источника. Слишком низкая
  плотность указывает на провал распознавания.
- **Доля нечитаемых символов** — высокая доля посторонних символов означает мусор
  на выходе.
- **Целостность таблиц** — строки тела должны совпадать по числу столбцов с
  заголовком.
- **Корректность формул** — математическая разметка должна оставаться
  синтаксически верной.

### Пример расчёта

Пусть документ содержит $N$ страниц, а суммарный объём распознанного текста равен
$C$ символов. Тогда средняя плотность оценивается как

$$\rho = \frac{C}{N}.$$

Если $\rho$ опускается ниже порогового значения, документ помечается как вероятный
провал распознавания и направляется на повторную обработку с другим режимом.

## Типичные дефекты

Чаще всего встречаются:

- перенос слова по дефису на границе строк;
- склейка нескольких столбцов таблицы в один;
- потеря выносных формул при низком разрешении скана;
- повтор колонтитула на каждой странице.

## Заключение

Надёжная обработка скана складывается из аккуратной конвертации, детерминированной
очистки и честной оценки качества. Автоматика снимает основную нагрузку, а ручная
вычитка остаётся там, где цена ошибки высока.
