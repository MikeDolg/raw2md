# Guidelines for document processing

The guide describes the standard order of work with incoming documents[^order]
and the roles responsible for each stage.

## Document intake

At intake, the format[^formats] and the integrity of the file are checked.
Damaged material goes back to the sender with the reason stated.[^reasons]

The registration number is assigned automatically after a successful check.
Documents received on the same day are numbered in sequence, whatever the
exact time of intake.

## Conversion

The conversion starts automatically after a successful intake. The engine is
chosen from the file type[^engines] without an operator. Temporary files are
kept in an isolated folder and deleted at the end.

## Quality control

The result is graded on a set of parameters: text density, the share of
unreadable characters, table integrity, and formula correctness.[^quality] The
final status is set automatically and written to the log.

[^order]: Approved by procedure No. 12 of 15.03.2024.
[^formats]: Accepted formats: PDF, DOCX, DjVu, Markdown.
[^reasons]: The exception is damage from a technical fault: in that case the
    transfer repeats automatically without a notice to the sender.
[^engines]: The table that maps formats to engines is in appendix A.
[^quality]: The threshold of each parameter is described in section §7 of the
    technical documentation.
